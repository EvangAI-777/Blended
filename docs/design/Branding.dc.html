Usage Guidelines

Logo Clear Space

Maintain a minimum clear space equal to the height of the letter 'x' on all sides of the wordmark.

Color Application

  • Accent Orange (#ff7f00): Interactive elements, active states, highlights, CTAs, focus indicators
  • Neutral Gray (#1d1d1d–#e0e0e0): Hierarchy, depth, accessibility (maintain sufficient contrast)
  • Never: Use accent on disabled/inactive states; use Layer 2 neutral gray (#323232)

Typography Hierarchy

  • Always use SemiBold (600) for headings and section titles
  • Use Regular (400) for body text and mode button labels
  • All-caps Reserved for dividers and metadata only
