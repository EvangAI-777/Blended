Blended Creative Pipeline

Two sequential stages: Creative (authoring) feeds Post (finishing)

Pipeline Details

Creative (Authoring)

  • Storyboarding: Panel-based narrative planning. Panels become keyframes in 2D Animation.
  • 2D Animation: Frame-by-frame drawing with F-curve interpolation. Same project data as Storyboarding.
  • 3D Animation: Modeling, rigging, lighting, rendering. Six modes: Sculpt, Model, Rig, Environment, VFX, Animate.
  • Game: Polygon budgets, LOD workflows, engine-export formats. Asset creation with real-time constraints.
  • Design: Graphic design, illustration, concept art. Shares animation timeline with 3D/2D content.

Post (Finishing)

  • Finalizing: Timeline assembly, QC, export-ready cuts. Receives output from any Creative section.
  • Compositing: Per-frame polish. Node-based color grading, effects, layering.
  • Audio: Mix and score. Timeline synchronized with video output. Supports both faders (traditional) and keyframes (animation-native) editing modes.

The Animation Engine

Every property in every section is keyframeable using the same F-curve interpolation system. The engine doesn't care whether you're animating object transforms, Grease Pencil stroke points, material parameters, or audio fader levels — it's just interpolation with full artistic control (ease-in/out, bounce, constant, linear).

  • Static work is animation with one frame.
  • Motion graphics is Design with keyframes.
  • Animated UI is Game with keyframes.
  • No special cases. Everything falls out of the same principle.
