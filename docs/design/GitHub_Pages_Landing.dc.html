Animation as the Shaping Discipline

Blended is built on a core truth: every creative property is keyframeable. Whether you're animating 3D objects, 2D stroke points, material parameters, or audio faders — it's all interpolation using the same F-curve system. One engine. Every content type.

What This Means

  • Static work is animation with one frame.
  • Motion graphics is Design with keyframes.
  • Animated UI is Game with keyframes.
  • No special cases. Everything falls out of the same principle.

For Animators

This means the timeline is never an afterthought. Whether you're building 3D rigs, painting frames, or compositing, keyframing is first-class. The craft comes first.

What is Blended?

Blended is a rebuild of Blender from the foundation up. It keeps what makes Blender powerful — the 3D modeling, the timeline, the node system, the GPL license — and simplifies everything else. A focused, opinionated tool shaped by animation as the core discipline.

The goal: free creative software that doesn't overwhelm. You open it, you pick what you're doing, and you get a focused lens onto powerful tools.

The Creative Pipeline

Work flows through Creative (authoring) → Post (finishing). Animation is the shaping discipline of both. One engine, every content type.

Every section shares the same animation engine. One timeline. One keyframe system. Static work is animation with one frame. Motion graphics is Design with keyframes. No special cases.

Workflow Example: From Concept to Finished Animation

1. Storyboard

Panel-based narrative. Each panel becomes a keyframe in 2D Animation.

2. 2D or 3D

Frame-by-frame drawing or 3D animation. One timeline, same keyframe system.

3. Finalize

QC, timing tweaks, export-ready cuts. Receives output from any Creative stage.

4. Post

Compositing, grading, audio. Timeline-synchronized finishing.

No export/re-import. No transcoding. Everything stays in the project. One animator. One timeline. One engine.

Why Blended

🎬 Animation-First Design

Animation shapes the core. Every property in every tool is keyframeable using the same F-curve system. One engine, every content type.

🎯 Focused Pipeline

Work flows from authoring through finishing. Pick what you're doing — Storyboarding, 2D, 3D, Game, Design — get a clean, purposeful interface.

📐 Rebuilt Foundation

39 Blender datatypes reduced to ~19. Removed fossils and cruft. The core is lean, coherent, and easy to extend.

🆓 Free & Open

GPL-2.0-or-later. All source code available. No vendor lock-in. Run it, modify it, learn from it.

🔗 Industry Formats

USD, glTF, FBX, OBJ, Alembic. Import/export at the boundary. The .blended file is your project; formats are translators.

⚡ Fast & Lightweight

Reduced codebase means smaller builds, faster startup, lower memory. The foundation reduction is real.

What's In Scope

✓ 2D & 3D Animation

The shaping discipline. Full timeline, F-curves, keyframes, all animation tools.

✓ 3D Modeling & Sculpting

Mesh modeling, sculpting, rigging, rendering. Full geometry node system.

✓ Game Asset Creation

Polygon budgets, LOD workflows, sprite sheets, engine-ready exports (Unity, Unreal, Godot).

✓ Graphic Design & Illustration

Concept art, UI design, illustration. Shares animation timeline with 3D content.

✓ Compositing & Post

Node-based compositing, video editing, audio mixing. Timeline-driven finishing.

✓ Extensible via Addons

Python API. Community-contributed workflows and tools. Asset library support.

Explicitly Not

  • Not a game engine. Blended authors content. It doesn't host runtime gameplay.
  • Not a feature-parity arms race. Every feature must serve animation or fit the scope. No "because Maya has it."
  • Not a kitchen sink. Fossils and legacy formats are cut. The codebase is lean.
  • Not Blender with a reskin. Foundation rebuilt from scratch. Data model simplified. Pipeline rethought.
